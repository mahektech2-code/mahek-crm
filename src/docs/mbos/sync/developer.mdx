The handset (Expo SDK 57, React Native, SQLite via `mbos-app/src/db`) is offline-first. Every write goes through `enqueue` into `sync_queue`; `syncNow` runs one pass that `POST`s a batch to `/api/mbos/sync` with the pull cursor; the server's `ingestSyncBatch` answers each item and `buildPull` returns the delta in the same response; `applyPull` merges it. Media and the location trail have their own queues, drained after records. Sign-in and upgrades take a full snapshot from `/api/mbos/bootstrap` (`buildBootstrap`).

## The outbox

<Code file="mbos-app/src/sync/queue.ts" symbol="enqueue" collapsed />

The key is `entityId:op:hash(payload)`. A **create** keeps the bare key, so a create sent twice is caught. An **update** repeated after the original landed gets `#n` appended — otherwise archive, unarchive, archive would return the first, long-synced item and never be sent, and the server's ledger would replay the first answer.

The server binds each upload to its parent with `bindMbosMedia` when the parent is written, and again when the file arrives naming it — whichever comes second. An unbound file past `attachments.orphanCleanupHours` is removed by the nightly sweep.

## Changing it safely

<Steps>
<Step title="Add a pulled column">
Add it to the handset's schema migration **and** the server's channel function. The bootstrap and delta must call the same function — never a second query. Older handsets drop it harmlessly.
</Step>
<Step title="Add a new kind of write">
Add the `entityType` to `SYNC_ENTITY_TYPES`, a `case` in `dispatchItem`, a handler with a zod schema, and the handset `enqueue` call. The wire test fails if either half is missing.
</Step>
<Step title="Never bind a JavaScript Date in raw SQL">
Pass `.toISOString()`, and type a number subtracted from a date (`::int`). Both have taken the whole delta down before; only a test that runs the query finds them.
</Step>
<Step title="Never refuse what can be retried">
A handler that throws answers retry. Return `rejected` only for a decision the salesman can act on, with a sentence that says how.
</Step>
</Steps>
