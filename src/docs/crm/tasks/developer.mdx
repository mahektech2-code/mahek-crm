Tasks are rows in `tasks`, owned by one person (`assignee_id`) and filed under one app (`app`). The CRM screen and the Tasks app read the same functions in `lib/tasks/service.ts`; every write is in `lib/actions/tasks.ts`; the rules are pure in `lib/tasks/rules.ts`.

## Map of the code

| Layer | File | What lives there |
|---|---|---|
| Route guard | `src/app/crm/tasks/layout.tsx` | `requireModule(user.id, "crm.tasks")` |
| Page (server) | `src/app/crm/tasks/page.tsx` | `myTasks`, `incomingTransfers`, filtered to `crm` and personal |
| Screens (client) | `src/app/tasks/_ui/screens.tsx` | `CrmTasksScreen` and the Tasks app's screens |
| Dialogs (client) | `src/app/tasks/_ui/dialogs.tsx` | the record, New task, Close, Transfer |
| Actions | `src/lib/actions/tasks.ts` | `createTask`, `updateTask`, `closeTask`, `reopenTask`, `transferTask`, `decideTransfer`, `withdrawTransfer`, `deleteTask` |
| Service | `src/lib/tasks/service.ts` | `myTasks`, `teamOf`, `taskDetail`, `canSeeTask`, `taskCounts` |
| Rules (pure) | `src/lib/tasks/rules.ts` | `closeProblems`, `transferRoute`, `managesBoth`, `teamBelow` |
| Upload | `src/app/api/tasks/proof/route.ts` | one screenshot, stored unparented until `closeTask` binds it |
