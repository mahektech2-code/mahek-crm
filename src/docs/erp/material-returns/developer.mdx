One pure engine, one service, one screen module with seven lists, and a `returnFlow` record panel. Every figure is read off the documents. The only new stock reading is a confirmed return outward, which is an outflow of its raw-material lot.

| Layer | File | What lives there |

Reuse writes `erp_fg_entries` / `erp_pack_entries` with `source_type = 'return'`. Rework, once completed, writes `erp_sfg_entries` with `source_type = 'rework'` on lot `RW<n>`, plus an `erp_sfg_qc` row at Pending. Scrap writes `erp_scrap_entries` with category `Chemical Scrap`. A reversal deletes the entry it posted, but only after locking the lot and checking that the stock is still there.
