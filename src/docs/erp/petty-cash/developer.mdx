Petty cash is one ERP screen (`expenses`) with two tabs, `expenses` and `credits`, both server modules in `src/lib/erp/screens/logistics.ts`. Writes go through the four generic ERP actions in `src/lib/actions/erp.ts`.

## Map of the code

| Layer | File | What lives there |
|---|---|---|
| Registry | `src/lib/erp/registry.ts` | The `expenses` screen and its two views |
| Tabs | `src/lib/erp/screens/logistics.ts` | `cashForm`, the `credits` and `expenses` modules, `setExpenseStatus` |
| Rules (pure) | `src/lib/erp/engines/cash.ts` | `cashBalances`, `cashKey` |
| Alerts (pure) | `src/lib/erp/engines/alerts.ts` | `duplicateExpenses`, `cashNegative` |
