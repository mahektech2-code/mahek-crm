The Masters are seven screen modules in `lib/erp/screens/masters.ts` (raw materials, purchase parties, products, sales parties, godowns, price lists, reference lists) plus **My customers** in `screens/logistics.ts`. Three of them write MahekOne's own tables (`customers`, and the catalogue's `products` through a side table); the rest write `erp_*` tables. Per-material duties are pure in `lib/erp/material-duties.ts` and wired in `material-duties-server.ts`.

## Saving a raw material

<Code file="src/lib/erp/screens/masters.ts" symbol="saveRawMaterial" collapsed />

Notes on what it does:

- `density` and `testing_list` are written only for a Chemical; otherwise `null` and `[]`.
- A save that sends no purchase rule keeps the stored one, or starts from Quotation for a chemical and Direct otherwise.
- A Quotation item's `preferred_supplier_id` is cleared.
- `price_paise` is in the update only when the caller holds `viewPurchaseMoney` — a clerk's save never overwrites it.
- New `serial_no` is `max + 1` under `lock table … in share row exclusive mode`.

## Changing it safely

<Steps>
<Step title="A new field on a MahekOne record">
Put it on the MahekOne table if the CRM should know it, or on the ERP side table (`erp_customer_profiles`, `erp_product_packing`) if only the ERP does. Never a second copy of a field the other app already holds.
</Step>
<Step title="A new drop-down">
Open values belong in `REF_LISTS`. A value a rule compares against belongs in a fixed list in `refs.ts`, because a manager rewording it would silently break the rule.
</Step>
<Step title="A new money column">
Mark it `pw` with the power that reveals it, and make the save leave it alone for a caller without that power.
</Step>
</Steps>

## Known gaps, with file references

| Gap | Where |
|---|---|
| Raw material name uniqueness is across all categories, but `itemPickLabels` is written for names shared across categories | `screens/masters.ts` `saveRawMaterial`; `engines/purchase-flow.ts` `itemPickLabels` |
| Item code is `req` on the form only; the save stores null and the lot number is built without it | `saveRawMaterial`; `engines/purchase.ts` `lotNumber` |
| My customers shows `monthlyTargetPaise` with no `viewSalesAmounts` check | `screens/logistics.ts` `myCustomers` |
| Clearing credit days on a customer saves null (city and phone are protected; credit days is not) | `saveCustomerDetails` |
| A price list's discount is the first `price_list_discount_terms` row read, with no ordering | `priceListsScreen` |
| The 18% used to derive a missing incl./excl. rate is a literal | `priceListsScreen` |
| Retire / restore on raw materials and suppliers, and every reference-list change, need only the screen | `masters.ts` actions |
