| Piece | Where | Notes |
|---|---|---|
| Route | `src/app/erp/my-tasks/page.tsx` | Renders `AppTasksPage` with this app |
| Module | `erp.myTasks` | Always open — in `ALWAYS_OPEN_MODULES`, which `moduleAllowed` honours |
| Shared page (server) | `src/app/tasks/_ui/app-tasks-page.tsx` | `myTasks` and `incomingTransfers`, narrowed by `shownInApp` |
| Screen (client) | `src/app/tasks/_ui/screens.tsx` | `AppTasksScreen` |
| Paths | `src/lib/tasks/rules.ts` | `APP_TASKS_PATH`, `shownInApp`, `taskLink` |

A task's notifications use `APP_TASKS_PATH` for the task's app, so they land in that app's bell. Adding My tasks to another app is a path in `APP_TASKS_PATH`, a page rendering `AppTasksPage`, a module marked always open, and a sidebar entry.
