`lib/erp/book.ts` is the whole bridge. When <Setting k="erp.orders.live" /> is on, `syncBookOrders(orderNos)` rewrites MahekOne's `orders` and `bills` copy of each ERP order number from its `erp_orders` lines, then recomputes the caches that read them. Three other places read the switch: the sheet projection (writes no order or bill), `recomputeOrderSystemHolds` (reads ERP lines instead of the Taken Order tab), and the ERP's own pending-party approval (withdrawn). Off, every function here returns without writing.

## Changing it safely

<Steps>
<Step title="Every new write that changes an order calls syncBookOrders">
A save that changes an ERP order's lines, status, value, billing or dispatch must end with `syncBookOrders(await orderNosOf(ids))` (or the order numbers it has). A write that forgets leaves the book stale until somebody else touches the order.
</Step>
<Step title="Never write the book from anywhere else">
The rows are a projection; anything written into them by another path is overwritten on the next rewrite.
</Step>
<Step title="Keep the keys">
`ERP-` and `ERPBILL-` are what keep the sheet projection's `SHEET-` / `SHEETPAY-` upserts off these rows. Changing them orphans every row already written.
</Step>
<Step title="Test with the switch on">
`erp-book.test.ts` sets `erp.orders.live` itself; a new case that forgets will pass vacuously, because off the bridge writes nothing.
</Step>
</Steps>

## Known gaps, with file references

| Gap | Where |
|---|---|
| The Call Log hold is not refreshed by `syncBookOrders`; it waits for the Taken Order sync or the nightly recompute | `book.ts` `syncBookOrders`; `recompute.ts` `recomputeEverything`; `services/taken-order-sync-service.ts` |
| A line with no details row is valued at a hardcoded 18% GST, not a setting | `book.ts` `lineValue` (`gstBp ?? 1800`) |
| `erp-book-sync` has no Admin Console button, so go-live needs shell access | `lib/jobs.ts`; `app/admin/platform-real.tsx` (runnable jobs list) |
| `recomputeErpOrderHolds` always reports `unmatched: 0`, so the shape matches the sheet's report but the figure means nothing | `book.ts` |
