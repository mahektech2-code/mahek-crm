Tasks are rows in `mbos_tasks`. The Sales Dashboard reads them through `tasksList` (single tasks) and `task-campaign-service.ts` (assignments), and writes them through `assignTaskCampaign` and its siblings in `src/lib/actions/sales.ts`. Automatic tasks are inserted by the handset handlers in `src/lib/actions/mbos.ts`, the lead services and the scheduled jobs in `src/lib/mbos-jobs.ts`. The form model is pure, in `src/lib/task-form.ts` and `src/lib/task-audience.ts`, because the dialog, the server and the handset all read it.

## Changing it safely

<Steps>
<Step title="An automatic task needs a key">
Set `source_type` and `source_id`, and check for an open task with the same pair before inserting.
</Step>
<Step title="Keep the form pure">
New field types go in `task-form.ts` with a label and a summary, and must be mirrored on the handset.
</Step>
<Step title="Keep the expected-count check">
It is what stops an assignment growing between review and save.
</Step>
</Steps>

## Known gaps, with file references

| Gap | Where |
