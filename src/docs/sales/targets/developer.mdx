Sales Targets is `src/app/sales/targets/` reading `src/lib/services/sales-target-service.ts` and writing through `saveSalesTarget` and `publishSalesTarget` in `src/lib/actions/sales-targets.ts`, every one of which opens with `requireCapability("target.set")`. The rows live in `sales_targets`, the mix bands in `sales_target_categories` and the revision trail in `sales_target_revisions`. `copyForwardSalesTargets` in `src/lib/recompute.ts` carries published targets into a new month. The Accounts door at `/accounts/targets` calls the same functions and adds a revision history drawer.

## Map of the code

| Layer | File | What lives there |
|---|---|---|
| Module guard | `src/app/sales/targets/layout.tsx` | `requireModule(user.id, "sales.targets")` |

| Screen (client) | `src/app/sales/targets/targets-screen.tsx` | The table, Add someone, the target drawer |

| Reads | `src/lib/services/sales-target-service.ts` | `targetableCandidates`, `mixCategories`, `baselineFor`, `existingCustomerTargetTotals`, `revisionsFor` |
| Writes | `src/lib/actions/sales-targets.ts` | `saveSalesTarget`, `publishSalesTarget`, `targetRevisionHistory` |
| Copy-forward | `src/lib/recompute.ts`, `src/lib/jobs.ts` | `copyForwardSalesTargets`, run in the nightly pass as `copy-forward-sales-targets` |
| Score | `src/lib/services/performance-service.ts` | Reads published targets only |

## Carried forward

<Code file="src/lib/recompute.ts" symbol="copyForwardSalesTargets" collapsed />

Idempotent: it only creates a row where the period has none, so a hand-triggered re-run touches nothing already there. `saveSalesTarget` clears `carried_forward` on any real save.

## Changing it safely

<Steps>
<Step title="Keep the whole target one write">
Figures and bands are one decision. Splitting them lets a revenue target publish with its mix missing.
</Step>
<Step title="Check target.set in the action">
A server action is a URL; the screen hiding a button is not a permission.
</Step>
<Step title="Read both band keys everywhere">
Any new reader of `sales_target_categories` must handle a category key and a formulation key. The handset wire once dropped formulation rows with an inner join and sent an empty mix.
</Step>
</Steps>
