# Approved shared assets

Read-only to the app: there is no upload feature. New assets arrive through reviewed commits.

- `fonts/` poster fonts plus `fonts.json` (family, weights, scripts, licence). **Interim** Noto fonts
  from the Phase 0 proof (decision D-7 / D-30 is still open).
- `logos/` Mahek logo variants (`mahek-light.png`, `mahek-dark.png`).
- `products/` approved pack image per product code (`M1433.png`, ...), keyed by product code.

**Provenance:** the logos and pack images are **placeholders exported from the approved prototype's
code-drawn artwork** (decisions D-6 and D-9: who produces the real files is still open). Replacing a
file with the real asset needs no code change.
